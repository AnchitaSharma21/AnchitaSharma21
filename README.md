## 🔬 Projects


<details>
<summary><b>🛡 SafeRoute — AI-Powered Safe Navigation</b> | Geospatial AI · Routing · Real-Time Systems</summary>

<br/>

**Problem**  
Traditional navigation systems optimize for speed or distance — not safety. Users may be routed through high-risk areas without awareness.

**What I Built**
- Context-aware navigation system prioritizing safety over shortest path  
- Real-time ingestion of crime-related data from multiple news sources  
- AI pipeline to convert unstructured text into geospatial signals  
- Dynamic routing that avoids unsafe zones  

**How It Works**
- News APIs → live incident data  
- Gemini API → extracts structured risk signals  
- H3 → converts locations into hex-based risk zones  
- OSRM → generates multiple routes  
- Routing logic → avoids high-risk areas  

**System Design**
- Fully serverless architecture (Next.js + Supabase)  
- Real-time processing pipeline  
- Interactive UI with safety zones (safe / caution / high-risk)  

**Stack**  
Next.js · Supabase · OSRM · H3 · Mapbox GL JS · Gemini API · News APIs  

**Key Insight**  
H3 enables computational spatial indexing, unlike heatmaps which are only visual
