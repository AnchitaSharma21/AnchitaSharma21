## ◈ Featured Project

<details open>
<summary>
&nbsp;<b>🩺 &nbsp;Non-Invasive Vitamin D Deficiency Prediction</b>&ensp;
<code>Healthcare AI</code>&ensp;<code>Predictive Modeling</code>&ensp;<code>Feature Engineering</code>
</summary>

<br/>

<table>
<tr>
<td width="50%" valign="top">

**Problem Statement**

Vitamin D deficiency affects over 1 billion people globally. Conventional diagnosis requires blood tests — slow, costly, and inaccessible in underserved regions. A non-invasive prediction pathway reduces time-to-detection.

**Approach**

End-to-end ML pipeline using lifestyle, dietary, and demographic attributes as proxy biomarkers. Focus: identifying high-risk individuals before clinical onset using structured tabular data.

</td>
<td width="50%" valign="top">

**Pipeline Stages**

```
Data Collection      ─── Health attribute surveys
      ↓
Preprocessing        ─── Null handling, normalization
      ↓
Feature Engineering  ─── Domain-driven feature design
      ↓
Model Training       ─── Classification algorithms
      ↓
Evaluation           ─── Accuracy, precision, recall
      ↓
Prediction Output    ─── Risk stratification
```

</td>
</tr>
